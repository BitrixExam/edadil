# Edadil Clone

Laravel-проект для сбора и просмотра цен на товары из разных магазинов с сохранением истории изменений цен.

Сейчас проект сфокусирован на backend-части:
- парсинг карточек и каталогов товаров;
- сохранение товаров и истории цен в базу;
- подготовка архитектуры под расширение на несколько магазинов;
- дальнейшая база для расчёта средней цены, аналитики и отображения динамики цен.

## Что умеет проект сейчас

- Сохраняет магазины в таблицу `shops`.
- Сохраняет товары магазина в таблицу `products`.
- Сохраняет историю цен и наличие в таблицу `product_prices`.
- Поддерживает отдельные парсеры для карточек товара и для каталогов.
- Позволяет добавлять новые магазины через реестр парсеров.
- Покрыт базовыми unit/feature тестами для текущих сценариев парсинга.

## Архитектура парсинга

Основная идея проекта: парсеры изолированы по магазинам и типу страницы.

### Основные сущности

- `Shop` — магазин.
- `Product` — товар конкретного магазина.
- `ProductPrice` — история цены и наличия товара.

### Основные слои

- `app/Parsing/Contracts`
  Контракты для парсеров магазинов, карточек и каталогов.
- `app/Parsing/Parsers`
  Реализации парсеров для конкретных магазинов.
- `app/Parsing/*Registry.php`
  Реестры, которые выбирают подходящий парсер по URL.
- `app/Services/ProductImportService.php`
  Общая логика сохранения товара и записи истории цены.
- `app/Console/Commands`
  Консольные команды запуска парсинга.

### Текущие команды

- `parse:product {url}`
  Парсит карточку товара и сохраняет цену.
- `parse:catalog {url}`
  Парсит страницу каталога и сохраняет товары пачкой.

## Запуск проекта

Проект запускается через Laravel Sail.

### Поднять контейнеры

```bash
./vendor/bin/sail up -d
```

### Установить зависимости и подготовить приложение

Если проект разворачивается впервые:

```bash
composer install
cp .env.example .env
./vendor/bin/sail artisan key:generate
./vendor/bin/sail artisan migrate
```

### Запустить тесты

```bash
./vendor/bin/sail artisan test
```

## Примеры использования

### Парсинг карточки товара

```bash
./vendor/bin/sail artisan parse:product "https://magnit.ru/product/123456/"
```

### Парсинг каталога

```bash
./vendor/bin/sail artisan parse:catalog "https://magnit.ru/catalog/112578-produkty_copy_219?shopCode=992301&shopType=6"
./vendor/bin/sail artisan parse:catalog "https://5ka.ru/catalog/ryba--251C13077/?page=2"
./vendor/bin/sail artisan parse:catalog "https://www.perekrestok.ru/cat/c/32/salaty"
```

## Ограничения текущей версии

- Нет frontend-интерфейса для просмотра товаров и графиков цен.
- Нет автоматического обхода каталогов по расписанию.
- Нет очередей и фоновых джобов для массового обновления.
- Нет канонической модели общего товара между магазинами.
- Часть каталогов уже требует не HTML-парсинга, а работы напрямую с API.
- `DiDom` используется как простой HTML-парсер, но для современных JS-сайтов этого может быть недостаточно.
